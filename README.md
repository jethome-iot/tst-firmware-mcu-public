# tst-firmware-mcu — прошивки микроконтроллеров стендов JetHome

Готовые прошивки микроконтроллеров, которые работают на стендах проверки
устройств JetHome, и документация к этим стендам.

**Скачать:** [релизы](../../releases). Релиз называется `<проект>/vMAJOR.MINOR`;
в нём образ `.bin` для прошивки, `.hex` и `SHA256SUMS`.

| Проект | Микроконтроллер | Что делает | Документация |
| --- | --- | --- | --- |
| `jxdio-expander` | CH32V003F4P6 | ответная часть разъёма JXDIO стенда JXD R6: экспандер, совместимый с PCA9535 (`0x20`), и замер DC OUT | [стенд JXDIO](docs/jxdio-stand.md), [регистры](docs/ch32v003/jxdio-expander.md) |

Прошивка CH32V003 через WCH-LinkE — [docs/ch32v003/flashing.md](docs/ch32v003/flashing.md).

Лицензии сторонних компонентов в прошивках — [THIRD-PARTY.md](THIRD-PARTY.md).

Этот репозиторий — витрина: релизы и документация попадают сюда автоматически.
Исходный код и история разработки живут в приватном репозитории.

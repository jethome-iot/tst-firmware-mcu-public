# jxdio-expander — регистры

Прошивка CH32V003F4P6 для стенда [JXDIO](../jxdio-stand.md): I²C target по
7-битному адресу `0x20`, совместимый с PCA9535 (NXP/TI), и замер напряжения DC OUT.
Адрес `0x21` и остальные не отвечают. Проверено на 100 кГц; на время обработки
байта CH32V003 растягивает SCL.

## Пины

| Пин | Функция |
| --- | --- |
| PC1 | I2C1 SDA |
| PC2 | I2C1 SCL |
| PC3 | INT, открытый сток, `0` — прерывание |
| PD2 | A3 — делитель DC OUT |
| PD1 | SWIO — программатор |

## Регистры

| Команда | Регистр | Доступ | С версии |
| --- | --- | --- | --- |
| `0x00` / `0x01` | входы, порты 0 / 1 | чтение | 0.1 |
| `0x02` / `0x03` | выходы | чтение и запись | 0.1 |
| `0x04` / `0x05` | инверсия полярности | чтение и запись | 0.1 |
| `0x06` / `0x07` | конфигурация: `1` — вход, `0` — выход | чтение и запись | 0.1 |
| `0x40` / `0x41` | напряжение DC OUT, мВ, u16 little-endian | чтение | 0.1 |
| `0x42` / `0x43` | средний код АЦП на PD2, u16 LE | чтение | 0.1 |
| `0x44` / `0x45` | средний код АЦП внутреннего опорного (VREFINT), u16 LE | чтение | 0.1 |
| `0x48` / `0x49` | версия прошивки: major / minor | чтение | 0.1 |
| прочие | — | читаются как `0xFF`, запись игнорируется | 0.1 |

Документация может описывать ещё не выпущенную версию: колонка «С версии» и версия в
`0x48`/`0x49` показывают, что есть у прошитого образа.

Как у PCA9535: первый записанный байт — команда; следующие байты переключаются
внутри пары регистров (`0x02` → `0x03` → `0x02` …); чтение без команды продолжает с
текущего указателя. Чтение, оборванное без NACK мастера (сброс мастера, ошибка
шины), оставляет указатель на регистр дальше: CH32V003 уже загрузил следующий байт.
После включения выходы `0xFF`, полярность `0x00`, конфигурация `0xFF`.
Двухбайтовое значение (`0x40`/`0x41` и другие) читается одной транзакцией:
оно фиксируется в начале чтения.

## Линии

Физическая линия одна — INT; остальные замкнуты внутри прошивки.

- **IO0_0 — INT.** Сконфигурирован выходом (`0x06` бит 0 = `0`) и записан `0`
  (`0x02` бит 0) → INT прижат. После включения INT отпущен.
- **IO0_n ↔ IO1_n, n = 1…7** — внутренний провод: сторона, сконфигурированная
  выходом, задаёт его уровень, `0` сильнее; без выходов провод читается `1`.
- **IO1_0** читает реальный уровень INT (с учётом других устройств на линии);
  сконфигурированный выходом — свою защёлку и на линию не влияет.

Входной регистр — уровень линии XOR регистр полярности.

**INT — только по команде.** Смена входов INT не взводит, в отличие от PCA9535.

## Напряжение

Каждые 10 мс — по 16 преобразований PD2 и VREFINT, среднее.
`мВ = код × 3300 × 13 / 1023`: опора — VDD 3,3 В, делитель 13. Шкала до 42,9 В.
Оценка VDD по опорному: `VDD ≈ 1,2 В × 1023 / код VREFINT` (VREFINT 1,17–1,23 В
по datasheet). Пересчёт идёт по номиналам; с эталонным прибором он ещё не сверен.
Опора АЦП — VDD от преобразователя стенда: его подстройка задаёт точность замера.

## Надёжность

- Если шина занята и событий I²C нет 1 с (мастер бросил транзакцию), I2C1
  инициализируется заново; значения регистров сохраняются.
- Сторожевой таймер (около 1 с) перезапускает чип, если основной цикл встал;
  регистры возвращаются к значениям после включения.
